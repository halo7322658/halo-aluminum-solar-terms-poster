# Halo｜铝型材行业节气微信海报生成器

> Halo Series · Aluminum Industry Solar Terms Poster Skill for Doubao Work

专为铝型材、门窗、建材企业打造的二十四节气微信海报生成技能。输入节气名称，自动产出适合朋友圈、公众号发布的企业级节气海报。

## ✨ 特点

- **行业垂直**：不是泛艺术海报，精准服务铝型材/门窗/建材行业
- **节气全覆盖**：内置二十四节气完整文案库，每个节气对应专属视觉方向
- **企业调性**：工业金属质感 + 商务克制美学，拒绝廉价节日风
- **隐藏式设计**：主标题醒目，辅助文字弱化融合，高级不杂乱
- **一键输出**：设计思路 + 海报图 + 生图提示词 + 朋友圈配文，四件套直接可用

## 📸 效果展示

**立冬 · 别墅落地窗视角**
> 室内暖光 vs 窗外雪景，用温差感体现门窗保温性能

**寒露 · 冷蓝薄雾氛围**
> 晨露、远山、金属线条，清冷理性的工业感

## 🚀 快速开始

### 安装方法

1. 下载本仓库全部文件
2. 将 `halo-aluminum-solar-terms-poster` 整个文件夹放入你的 `.user_skills` 目录
3. 重启豆包工作，技能自动加载

> 找不到 `.user_skills` 目录？一般在：
> `C:\Users\<你的用户名>\AppData\Local\Doubao\User Data\Default\.doubao\agent_mode\workspace\.user_skills\`

### 使用示例

安装后直接在豆包工作里说：

```
帮我生成一张立冬节气的铝型材微信海报，宣传重点是系统门窗，高端商务感。
```

```
做个秋分光伏支架海报，清洁能源方向。
```

```
Halo技能，来一张冬至门窗保温主题海报。
```

# 详细执行规则## 执行流程1. 拆解节气意象，结合铝型材业务卖点，梳理设计思路2. 调用图片生成工具，产出 9:16 竖版海报（适配手机全屏、短视频封面、朋友圈竖图）3. 输出完整可复制的生图提示词4. 撰写一段简短正式的微信朋友圈配文## 视觉硬性规则1. **主体必须包含铝型材元素**：铝合金型材截面、门窗型材、建筑幕墙、工业框架、光伏支架、机械结构件、铝挤压线条任选其一或组合；禁止纯风景无型材画面。2. **节气氛围自然融入**：春芽、夏柔光、秋叶、冬霜雪等作为点缀，不能抢占铝型材主体。3. **风格定位**：企业商务宣传、克制工业美学，排版干净，文字层级清晰，微信小图缩略也能看清主标题。4. **色彩基准**：主色调优先银灰、铝白、石墨黑、深海蓝；节气色彩仅做局部点缀，不大面积高饱和。5. **材质表现**：金属拉丝、阳极氧化质感、细腻金属高光，型材结构线条锐利干净。6. **画幅比例**：9:16 竖版，适合手机全屏、短视频封面、朋友圈竖图展示。7. **文字色彩层级（隐藏式设计）**：   - 主标题（节气名称）：纯黑色、粗体、大字号，视觉焦点唯一   - 辅助文案（行业关联句、品牌价值句）：纯白色、小字号、低透明度，与浅背景自然融合   - 视觉效果：远看/缩略图只看到黑色节气主标题，凑近细看才能发现白色小字说明   - 目的：克制高级感，避免文字堆砌，同时保留完整企业信息## 海报文案规则海报画面内置文案固定三段式：1. 节气主标题2. 铝型材行业关联短句3. 品牌价值短句参考文案库见 [solar-terms-copy.md](solar-terms-copy.md)。若用户提供宣传重点，文案必须围绕该重点展开。## 禁止清单- 不要纯风景节日海报，缺少铝型材元素- 禁止卡通插画、二次元、夸张电商促销风- 禁止模糊、软塌无结构的金属质感- 不要文字堆砌，画面拥挤杂乱## 输出格式严格按以下结构输出：**【设计思路】**2～4 句话，说明节气意象、型材元素、色彩与排版逻辑**【海报】**生成 9:16 竖版海报图片**【生图提示词】**完整中英文提示词，方便二次修改复用**【朋友圈配文】**适合铝企销售/市场转发的简短文案
